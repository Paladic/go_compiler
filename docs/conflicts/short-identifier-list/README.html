Списки перед := и =

После первого имени впереди запятая. В эксперименте Bison должен либо свернуть имя в identifier_list, либо в primary_expression для expression_list. Оператор ещё не виден. В рабочей грамматике оба оператора используют expression_list; AST проверит, что слева от := стоят простые идентификаторы.

a, b := pair()
a, obj.field = pair()
a, obj.field := pair() // отклонить при проверке AST
